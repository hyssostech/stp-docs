## Prerequisites 

Before using the SDK: 

1. Install a supported version of the Sketch-thru-Plan Engine.
2. Verify all required runtime dependencies.
3. Ensure access to the target STP environment.
4. Review the installation and engine setup documentation.

## Development Workflow 

1. Install Sketch-thru-Plan.
2. Configure and start the STP Engine.
3. Follow the Getting Started guide for your SDK.
4. Review relevant guides and API references.
5. Develop and test your integration or plugin.

## Documentation Versioning

Documentation tracks the currently supported SDK and engine releases. Refer to release notes and version-specific guidance when upgrading existing integrations.
